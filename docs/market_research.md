# 시장 조사 보고서: AI 기반 자동 분류 Todo 앱

## 1. 개요
기존의 수동적인 Todo 앱 시장에서 AI를 활용하여 사용자의 인지 부하를 줄여주는 차세대 생산성 도구 기획을 위한 분석입니다.

## 2. 경쟁 서비스 분석
- **Todoist**: 필터 기능은 강력하나 사용자가 직접 규칙을 설정해야 함.
- **Any.do**: 깔끔한 UI를 제공하지만 AI 기반의 지능적 분류는 부족함.
- **Motion**: AI가 캘린더를 정리해주지만, 단순 할 일 목록의 카테고리화는 부차적임.

## 3. 차별화 포인트 (USP)
- **Auto-Tagging**: 할 일을 입력하면 AI가 내용(업무, 개인, 학습 등)을 파악해 자동으로 태그를 부여.
- **Smart Priority**: 사용자의 과거 수행 패턴을 분석하여 실제 마감이 급한 일부터 동적으로 우선순위 재배치.
- **Contextual Reminder**: 시간뿐만 아니라 사용자의 위치나 현재 작업 중인 앱의 맥락을 파악해 알림 최적화.

## 4. 결론
시장은 성숙 단계이나 'AI를 통한 완전 자동화된 관리' 경험은 아직 초기 단계임. 기획 단계(3단계)에서 '자동 분류 알고리즘'에 집중하여 PRD를 작성할 필요가 있음.
