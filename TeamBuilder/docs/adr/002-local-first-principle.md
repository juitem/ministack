# ADR-002: Local-First Principle (로컬 우선 원칙)

## 상태 (Status)
Accepted (2026-03-28)

## 컨텍스트 (Context)
에이전트 시스템이 전역 설정에만 의존할 경우, 한 프로젝트에서 전문가의 지침을 수정하면 다른 모든 프로젝트에 영향을 미치는 부작용이 있습니다. 또한 프로젝트마다 고유한 도메인 지식과 팀 구성이 존재해야 합니다.

## 결정 (Decision)
- **Local Over Global**: 모든 명령어 실행 시 현재 작업 디렉토리(CWD)의 리소스(`roles/`, `state.json`)를 전역 리소스(Global Lib)보다 먼저 참조합니다.
- **Recruit to Local**: 인력을 채용한다는 것은 전역 템플릿을 현재 프로젝트 폴더로 복사하여 '독립적인 인스턴스'로 만드는 행위임을 명확히 합니다.

## 결과 (Consequences)
- 각 프로젝트는 전역 설정의 오염 없이 자신만의 전문가 팀을 커스터마이징하고 성장시킬 수 있습니다.
- 프로젝트 전체를 복사하거나 이동해도 상태와 인력 구성이 그대로 유지됩니다.
