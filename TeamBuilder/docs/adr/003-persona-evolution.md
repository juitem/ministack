# ADR-003: Persona Evolution Mechanism (페르소나 진화 메커니즘)

## 상태 (Status)
Accepted (2026-03-28)

## 컨텍스트 (Context)
단순한 페르소나 템플릿은 시간이 지나도 능력이 고정되어 있습니다. 하지만 실제 인재는 프로젝트 경험을 통해 성장합니다. 에이전트 역시 프로젝트의 피드백이나 지식을 학습하여 더 스마트한 버전으로 탄생할 필요가 있습니다.

## 결정 (Decision)
- **Clone**: `clone` 명령어를 통해 기존 전문가의 지식을 상속받은 '파생형'을 생성합니다.
- **Train (Knowledge Injection)**: `train` 명령어를 통해 텍스트 형태의 지식을 전문가의 `.md` 파일에 영구 기록합니다.

## 결과 (Consequences)
- "프로젝트 A에서 성공적으로 커널 최적화를 마친 신입 커널 전문가"가 "시니어 커널 전문가"로 진화하는 과정을 지원합니다.
- 지식의 선순환 구조가 형성되어 시스템 전체의 전문성이 누적됩니다.
