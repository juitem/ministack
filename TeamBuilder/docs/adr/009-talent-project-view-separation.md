# ADR-009: Separate Talent vs. Project View (역할 기반 뷰 분리)

## 상태 (Status)
Proposed (2026-03-28)

## 컨텍스트 (Context)
현재 대시보드는 하나의 화면에서 '미션 수행(Workflow)'과 '에이전트 관리(Recruit/Train)'를 동시에 처리하고 있습니다. 프로젝트가 복잡해짐에 따라, 실행 중인 작업을 추적하는 '실전' 모드와 에이전트의 역량을 키우는 '성장' 모드를 분리하여 인지 부하를 줄일 필요가 있습니다.

## 결정 (Decision)
- **Personnel Agency (인재 관리 뷰)**: 에이전트를 영입(Recruit), 훈련(Train), 성향 분석(Onboard)하는 데 집중하는 독립적인 대시보드 화면을 구축합니다.
- **Mission Control (프로젝트 수행 뷰)**: 현재 활성화된 메인 미션과 워크플로우 캔버스 상에서의 직무 위임과 실행 현황을 모니터링하는 데 집중합니다.
- **Tab-based Navigation**: 대시보드 상단에 탭이나 스위치를 두어 두 환경 사이를 직관적으로 전환할 수 있게 합니다.

## 결과 (Consequences)
- **UX 집중도 향상**: 사용자는 현재 수행 중인 태스크의 양에 따라 적절한 관리 도구를 선택적으로 사용할 수 있습니다.
- **확장성**: 추후 인재 관리 뷰에서 '에이전트 성과 지표'나 '훈련 결과 미리보기' 등 심화 기능을 추가하기 용이해집니다.
- **정체성 강화**: 에이전트를 단순한 도구가 아닌, 독립적인 '인격체'이자 '자산'으로 대우하는 시스템 철학을 더욱 명확히 합니다.
