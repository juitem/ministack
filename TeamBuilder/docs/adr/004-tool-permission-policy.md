# ADR-004: Tool Permission & Selection Policy (도구 권한 및 선택 정책)

## 상태 (Status)
Proposed (2026-03-28)

## 컨텍스트 (Context)
에이전트가 사용할 수 있는 도구가 너무 많으면 혼란을 야기하고 보안상 위험할 수 있습니다. 반면 너무 적으면 전문성을 발휘하기 어렵습니다. 사용자가 에이전트의 도구 사용 범위를 투명하게 통제할 수 있는 메커니즘이 필요합니다.

## 결정 (Decision)
- **Role-based Recommendation**: 각 페르소나 파일(`.md`)에 '권장 도구(Recommended Tools)' 목록을 정의합니다.
- **User-driven Selection**: 유저가 실제로 에이전트를 프로젝트에 투입할 때, 권장 목록 중에서 실제로 사용할 도구를 **체크박스 형태로 선택**하도록 유도합니다.
- **State Integration**: 선택된 도구 목록은 `state.json`의 `active_tools` 필드에 저장되어, 프롬프트 생성 시 해당 도구의 매뉴얼만 포함되도록 합니다.

## 결과 (Consequences)
- **보안**: 에이전트가 허용되지 않은 위험한 도구(예: `delete_all`)를 사용하는 것을 방지합니다.
- **효율**: 프롬프트의 길이를 최적화하여 AI의 집중력을 높입니다.
- **투명성**: 사용자는 에이전트가 어떤 능력을 가지고 작업에 임하는지 명확히 인지하게 됩니다.
