# AI Agent Trend Tracker 구축 시나리오

## 1. 프로젝트 개요 (Mission)
- **목표**: AI 에이전트 코딩의 최신 기술 동향(논문, GitHub, SNS)을 수집하여 핵심을 요약하고, 이를 웹 대시보드에 저장/전시하는 자동화 시스템 구축 및 유지보수.

## 2. 순차적 수행 단계 (Workflow)

### Phase 1: 리서치 및 기획
1.  **동향 조사**: 현재 가장 핫한 에이전트 프레임워크와 뉴스 소스 파악.
2.  **기획 (PRD)**: 어떤 데이터를 수집하고 어떤 형태로 보여줄지 정의.

### Phase 2: 설계 및 인프라
3.  **아키텍처 설계**: 스크래핑 엔진, DB 저장 방식, 웹 프레젠테이션 레이어 설계.
4.  **데이터 스키마 정의**: 요약된 지식을 저장할 구조 설계.

### Phase 3: 개발 및 구현
5.  **수집기 구축**: 외부 정보를 긁어오는 스크래퍼 개발.
6.  **요약 엔진 연동**: LLM을 활용한 데이터 가공 로직 구현.
7.  **웹 대시보드 개발**: 사용자가 정보를 볼 수 있는 인터페이스 구축.

### Phase 4: 검증 및 운영
8.  **보안 및 검증**: API 키 관리 및 데이터 정합성 체크.
9.  **유지보수**: 새로운 뉴스 소스 추가 및 시스템 최적화.

## 3. 필요한 전문가 팀 (Team Requirements)

| 역할 (Role) | 담당 전문 기술 | 투입 단계 |
| :--- | :--- | :--- |
| **researcher/market** | 외부 기술 트렌드 분석 및 뉴스 소스 식별 | Phase 1 |
| **product/base** | 요구사항 정의 및 기능 명세서(PRD) 작성 | Phase 1 |
| **architect/base** | 전체 시스템 구조 및 데이터 흐름 설계 | Phase 2 |
| **engineer/scraper** | 데이터 수집 및 가공 엔진 개발 (Python/Playwright) | Phase 3 |
| **engineer/web_ux** | 대킨보드 UI/UX 구현 (React/Vite) | Phase 3 |
| **reviewer/security** | 데이터 보안 및 시스템 안정성 검토 | Phase 4 |
